# Sky Islands {Islands}

Floating sky islands, archipelagos, towers, ruins and surface geyser launchers for Minecraft **26.3** (Fabric).
A port of *Sky Lands* (DeepCanionStudio, MIT) that uses **only vanilla blocks, items and entities**.

**Requires:** Minecraft 26.3, Fabric Loader 0.19.5+, [Fabric API](https://modrinth.com/mod/fabric-api) (0.163.0+26.3 or newer), Java 25.

## Building it on GitHub (no local setup)

1. Create a new **empty** GitHub repository.
2. Put this project in it so that `build.gradle`, `settings.gradle`, `src/` and the `.github` folder are at the **top level**
   of the repository (not inside an extra folder). The project has about 570 files, and GitHub's web "upload files"
   page only accepts 100 at a time, so use one of these:
   * **GitHub Desktop** (recommended): clone your new repo, copy this project's *contents* into it, then *Commit* and *Push*.
     Make sure the `.github` folder is included (it starts with a dot, so some tools skip it).
   * or the command line, from inside this folder:
     ```
     git init
     git add .
     git commit -m "Sky Islands"
     git branch -M main
     git remote add origin https://github.com/YOUR-NAME/YOUR-REPO.git
     git push -u origin main
     ```
3. Open the repo's **Actions** tab. The `build` workflow (`.github/workflows/build.yml`) starts by itself on every push (about 2-4 minutes). It installs Gradle itself, so it works even if the Gradle wrapper jar did not upload.
4. When it is green, open the run, scroll to **Artifacts**, and download `Artifacts`. Inside is `sky-islands-2.9.1.jar`
   (ignore the `-sources` jar). Put that jar in your `mods` folder next to Fabric API.

If the build is **red**, open the failed step, copy the first 20 or so lines containing `error:` and send them over;
each one points to an exact file and line.

## What is in it

| Feature | How it works |
| --- | --- |
| Islands, archipelagos, castles, towers, arenas, village | Data pack in `src/main/resources/data` (jigsaw structures + templates). Islands now spawn in **every** overworld biome. |
| Autumn (poplar) islands | Same data pack: poplar wood, orange/red/yellow poplar leaves, red sand, red shrubs, rose bushes. |
| Geyser launchers | Data pack functions (`function/geyser`). Standing near one makes your gravity negative along a curve (about +430 blocks) and switches off fall damage until you land. |
| **Snow and ice under islands** | `GroundFreezer`: after a chunk generates, columns with an island far above the real ground get the snow layer / ice vanilla would have placed at ground level (vanilla puts it on the island's top instead, leaving bare patches and unfrozen rivers below). |
| **No snow on islands in mild biomes** | `BiomeAltitudeMixin`: above y=165 the temperature used for snow/ice ignores altitude. Biomes that are freezing at sea level (snowy plains, frozen ocean, snowy taiga...) still snow, so glaciated islands keep their snow. |
| **Fading music** | `MusicController` (client). Skyborn starts when a geyser launches you and fades out when you land. Sky tracks (now five: Swaying Islands, An Island's Peace, Breathtaking View, Island's Sorrow, Singing Islands) fade in above y=200 and fade out below y=185, with a gap between tracks and never the same track twice in a row. Vanilla music fades out as ours fades in, and stays silent meanwhile. |
| **Clouds** | `CloudSpawner` + `CloudParticle` (client). A port of the original mod's method: huge camera-facing translucent particles spawned in bursts near you, drifting, fading in and out. |
| **Sky light through islands** | `ChunkSkyLightSourcesMixin`: the sky-light "lowest source" height of a column that has an island above a big air gap is found under the island, so the ground below is no longer in shadow. Built from the real 26.3 light engine source. Trade-off: the inside of island buildings counts as open sky and is fully lit. Existing chunks keep their old light until they are relit. |
| **Maps** | `MapItemMixin`: a map remembers (in its custom_data) whether it was first used in the sky. Maps made below the islands ignore them and show the ground; sky maps show only the islands and solid sky blue elsewhere. |
| **Fluids** | `FlowingFluidMixin`: island water/lava cannot flow out of the island. "Generated" means inside the island's structure area, so blocks a player adds *inside* an island are treated as part of it; anything placed in open sky behaves normally. (The falling-block cleanup was removed in 2.6.0 together with the sand islands.) |
| **Deserts** | The sand/desert islands are gone. Desert, badlands and savanna biomes now use the temperate (golden) islands, arenas and structures, and golden foliage tint applies over them too. |
| **Music toasts** | `MusicToast` (client): the now-playing box for every Sky Islands song (the five sky tracks, Skyborn and the boss theme), shown according to the vanilla *Music Toast* setting: Never = nothing, Pause Screen = only while the pause menu is open, Pause Screen and Toast = also slides in from the left edge for about 5 seconds when a song starts. The box is the mod's own 160x32 9-slice texture and the icon is a hand-drawn cloud that bobs 2 pixels every half second; both are baked into the code as pixel rectangles, so there is no texture file to load. |
| **Boss music** | `MusicController` (client): while a Sky Illusioner is within 64 blocks, *Battle amongst the Clouds* fades in quickly (looping) while sky music, the geyser song and vanilla music fade out. When the boss is dead it fades out and normal music can play again. |
| **Golden foliage** | `GoldenFoliageTint` (client): only on floating islands (a tall air gap below the block), not on mountains. Leaves, grass, grass blocks and ferns on islands over plains, forests, taiga, rivers and cooler oceans are golden yellow. Desert, badlands and savanna are golden too; jungles, swamps, warm oceans and snowy biomes keep their own colours. Those islands also have gold ore instead of emerald ore (data). |
| **Orange grass** | `AutumnGrassTint` (client). Grass high up and near any autumn block (poplar, fallen leaves, red shrubs, red sand, roses) is tinted dappled-forest orange (`#df6827`), whatever biome the island floats over. |
| **Sky arena boss** | `ArenaBoss` (server) + `worldgen/template_pool/skyarena_fight.json`. The temperate sky arena is two structures that share one structure set (50/50): `sky_islands:skyarena_chest` (plain tuff centre, no lanterns or soul fire, keeps its chest) and `sky_islands:skyarena_fight` (the boss arena), whose processor always swaps the chest for an invisible `barrier` marker. The marker puffs black smoke; a player within 5 blocks removes it, a spawn sound plays and a Sky Illusioner (vanilla Illusioner, 200 health, boss bar) appears. If it falls off the arena it is teleported back to the centre. The fight has three phases: above 2/3 health it holds a diamond axe and runs at you at half speed (no mirror image spell, visible axe), swinging about once a second like a Vindicator (9 damage, and a 25% chance to disable a raised shield for 5 seconds); if you stay out of its reach for 2 seconds (e.g. you pillar up) it switches to a bow that fires 1.5x faster than normal until it can reach you again. Reachability is sampled every 4 ticks and smoothed (unreachable adds time, reachable removes it twice as fast), and the boss keeps its last player as target when line of sight is lost, so the timer no longer restarts by accident; from 2/3 to 1/3 health it shoots arrows with its bow, and if it cannot see its target for 2 seconds (same smoothing as the reach timer: unseen adds 1 per tick, seen removes 2) it **rains 10-20 arrows** (one per tick) on every player within 40 blocks, landing within 3 blocks of each player and starting up to 12 blocks above them (a ceiling stops the rain), so hiding or pillaring out of sight does not work; below 1/3 it drops the bow and attacks with evoker fangs (rings when you are close, a long line otherwise, about every 1.2 seconds; the line is 8 fangs long, so fangs are only cast within 10 blocks) and, when its target is farther than 10 blocks, takes a **diamond spear** in its raised hand (the same arm pose as the axe, via `IllusionerAxePoseMixin`) and throws one every 3 seconds (first after a 1 s wind-up), with the arm swing as the throw: the spear is one `item_display` entity flown by the mod itself (`SpearVisual`) showing the diamond Wind Spear's flat in-hand sprite as an extruded model (the same slab as the `Windspear.obj` model; Minecraft cannot load OBJ files, so it is rebuilt as `models/item/diamond_windspear_projectile.json`), speed 2.2 blocks/tick, slight drop, aimed high to compensate, turned every tick to point along its path and spinning about its own length (`SpearVisual.SPIN_DEGREES_PER_TICK`, 0 for no spin; `SpearVisual.SCALE` for the size). The spear in its hand is a diamond Wind Spear. 8 damage on a hit, stopped by a raised shield facing it, vanishes on a block. Spears left over from a restart are removed when they load and, every 10-15 seconds (the first after 6), sends a **wind gust**: a charging sound and wind particles at the feet of every player within 24 blocks for 1 second, then a real `wind_charge` bursts on the ground at their feet (owned by the boss) and the vanilla explosion throws them up (`WIND_CHARGES_PER_PLAYER`, 1 by default; more charges, more height). Vanilla explosion launches also flag the player to ignore the fall damage of that flight, so the flag is cleared every tick while they are airborne (reflection on `Player`, looked up by name; the log says whether it was found) and the landing hurts normally. As each player is launched the boss also raises a spear and, once that player is near the top of their flight (6 to 16 ticks later), throws it straight at them, aimed where they will be if they keep their course, so they have to dodge it in mid-air. Drops 5-10 diamonds, 3-8 iron ingots, 5-12 gold ingots and (90%) a random enchanted book (level is the maximum or one below it; single-level enchantments are level 1), rolled in code (`onDeath`). The boss is immune to fire and lava (permanent hidden fire resistance), because the arena has soul fire. Its skin is `src/client/resources/assets/minecraft/textures/entity/illager/illusioner.png`, which replaces the vanilla Illusioner texture (the boss is the only Illusioner in this mod). The fight arena's floor centre is a 3x3 pattern (Blackstone corners, Obsidian sides, Crying Obsidian in the middle); The middle block is the real `sky_islands:glowing_obsidian` block, placed by the template itself (`skyarena_fight.nbt`). It is a Crying Obsidian copy with its own texture and item: it can be mined with a diamond pickaxe or better, drops itself, and can be placed anywhere (creative Natural Blocks tab, after Crying Obsidian). The ritual only works while it sits in the pattern: Blackstone on the four corners and Obsidian on the four sides, at the same height. The old pattern-conversion code is gone. **Respawn:** right-click the glowing obsidian with a plain Book (not an Enchanted Book, which the boss drops) while the boss is gone. The book is used up (not in creative) and floats above the altar, spinning and rising slowly while enchanting-table glyphs stream in from around the arena; then it shoots up with a trail and the boss re-appears at full health. While the book rises the **lower part of the arena is reset** (`ArenaReset`): everything from the bottom of the arena up to 5 blocks above the altar is put back as it generated, bottom to top, so blocks players placed there vanish and blocks they broke come back; the columns directly above the middle of the pit (the opening in the roof ring, found by flood fill from the altar over columns with nothing of the template above them) are cleared to air up to 30 blocks above the altar (`TALL_TOP_ABOVE_ALTAR`) (a placed chest is broken so its items drop; players standing where a block returns are lifted out of it). The rest of the upper part (the roof ring and towers, 6+ blocks above the altar) keeps whatever players placed or broke. The reference layout is read from `skyarena_fight.nbt` in the mod's resources, and the arena's random rotation is worked out by matching it against the world, so an altar that players built elsewhere (no arena around it) is left alone; turn it off with `arenaResetOnRespawn=false` in `config/sky_islands.properties`. The ritual does nothing while the boss is alive or waiting, and on Peaceful. Does not wake on Peaceful. The soul soil is set into the floor with the soul fire in the block above it. The chest/fight split is the two `weight` values in `worldgen/structure_set/skyarena.json`; to add the boss to the other arenas (arid, lavic, ice) copy the `rule` processor from `skyarena_fight.json` into their pools. |

## Settings (no rebuild needed)

On first launch the game writes `config/sky_islands.properties`. Edit it with the game closed. Highlights:

* `musicEnabled`, `skyMusicEnterY` (200), `skyMusicExitY` (185), `skyFadeInTicks`, `skyFadeOutTicks`, `skyMusicGapTicks`,
  `launchFadeInTicks`, `launchFadeOutTicks`, `bossFadeInTicks` (30), `bossFadeOutTicks` (60) (20 ticks = 1 second)
* `cloudsEnabled`, `cloudSpawnChance` (lower = fewer clouds, faster game), `cloudsPerBurst`, `cloudSpread`,
  `cloudBaseY`, `cloudHeightVariation`
* `orangeGrass`, `orangeGrassMinY`, `goldenFoliage`, `goldenFoliageMinY`
* `arenaBossHealth` (200), `arenaBossRegen` (4; health regained every 2 seconds once the boss has gone 20 seconds without taking damage, in every phase; 0 turns it off), `arenaResetOnRespawn` (true)
* `lightThroughIslands`, `skyMaps`, `naturalFluidsContained` (server side; turn any off to get vanilla behaviour back)

The music files are `src/client/resources/assets/sky_islands/sounds/music/*.ogg`. To swap a track, replace the file
with another **Ogg Vorbis** file of the same name (Opus-in-Ogg will not play) and rebuild. Track names are listed in
`MusicController.java` and `sounds.json`.

## Spots most likely to need a tweak (written without being able to compile)

The code was checked against Fabric API 26.3's own source and published mapping data, but not compiled or run.
If the build fails, the likely candidates are small name differences in:

* `FadingSound`: the protected fields `volume`, `looping`, `relative`, `attenuation`.
* `CloudParticle`: `scale`, `setSize`, `setLifetime`, `setAlpha`, and the fields `friction`, `gravity`, `hasPhysics`, `xd/yd/zd`.
* `AutumnGrassTint`: `Blocks.SHORT_GRASS`, `BlockAndTintGetter.getBlockState`.
* `MusicController`: `player.getAttributeValue(Attributes.GRAVITY)`, `SoundManager.isActive/play`.
* `MapItemMixin` / `ChunkSkyLightSourcesMixin` / `FlowingFluidMixin`: written against the real 26.3 source (signatures checked), but not run. If one fails to apply, the log says `Mixin apply failed`; the rest of the mod still works.
* `GroundFreezer`: `ServerChunkCache.getGenerator()/randomState()`, `ChunkGenerator.getBaseHeight(...)`, `ServerLevel.getBiome`.

The `BiomeAltitudeMixin`, `VanillaMusic` and the biome-temperature lookup in `GroundFreezer` are written so that a wrong name cannot break the game: they just log a
warning and that one feature stays off. Search `latest.log` for `Sky Islands` or `Mixin` to see.

## Wind Spears

Seven new items (`sky_islands:wooden_windspear` ... `netherite_windspear`, class `WindSpears`), one per vanilla spear tier. Each is registered as a copy of the matching vanilla spear (all its data components are copied at start-up), so poking with it, its damage, durability, repair material and the Lunge enchantment are exactly the vanilla spear's. The right click is replaced:

* **Throw**: right click throws the spear like a trident (with the vanilla breeze `entity.breeze.idle_air` sound, one of its four variants, instead of the trident throw sound; the hit and landing sounds are still the trident's) (speed 2.5, slight drop), spinning in flight (`SpearVisual`). A hit does the spear's normal attack damage (read from its attack damage attribute) plus Sharpness (0.5 x level + 0.5), as a trident-type hit credited to the thrower; throwing costs 1 durability (Unbreaking applies; the last point cannot be spent). It stops at the first block or entity and drops there, to be picked up. Creative players throw a copy (10 tick delay) that just vanishes. Looting only applies to the poke (a thrown spear is not in the hand when it kills).
* **Loyalty** (this mod's own enchantment, max III): after hitting something or landing the spear flies back into the thrower's inventory.
* **Piercing** (own, max IV): the thrown spear goes through that many extra entities.
* **Riptide** (own, max III): the right click launches the player in the direction they look, on land or in the air, but not in water or lava; 3 second cooldown (a message shows while it recharges); 1 durability per use. The new velocity is sent straight to the player's client (`ClientboundSetEntityMotionPacket`). Riptide cannot be combined with Loyalty or Piercing (and a Riptide spear cannot be thrown).
* **Wind Burst** (vanilla, allowed through `enchantable/mace`): launches things upward, about 7 / 12 / 18 blocks at levels I / II / III (`BURST_LIFT`). On a Wind Spear **without Riptide**, any tick the player is blocking (attack + use; the cooldown stops repeats) whatever entity they look at within 5 blocks (and not behind a solid block) is thrown up; nothing in reach means nothing happens and nothing is spent. On a Wind Spear **with Riptide**, every poke (a press of attack, even when it hits nothing; the client reports it with `WindPokePayload`) throws the holder up with a small push the way they look, and the landing does not hurt (not in water, lava or rain). The Riptide poke launch works twice per flight, like a double jump (`MAX_POKE_BURSTS`, a second apart: `POKE_BURST_COOLDOWN_TICKS`, so a Lunge jab fits between the two launches: Wind Burst, Lunge, Wind Burst), then is off until the player lands: on the ground, in water, riding something or touching down on a slime block. Riptide's own right-click launch is unchanged. The block launch has a 2 second cooldown (`BURST_COOLDOWN_TICKS`); every launch costs 1 durability. Note that the mace tag also lets Density and Breach onto Wind Spears; they do nothing there.
* **Quick Charge** (vanilla, allowed through `enchantable/crossbow`): the charge before letting go throws the spear takes 3 ticks less per level (10 -> 7 -> 4 -> 2, `QUICK_CHARGE_TICKS_PER_LEVEL`). It cannot be combined with Riptide (`data/minecraft/tags/enchantment/exclusive_set/riptide.json`), and a spear that somehow has both ignores Quick Charge.
* **Liquid drag**: a flying spear keeps 60% of its speed each tick in water (`WATER_DRAG`, with bubbles) and 40% in lava (`LAVA_DRAG`), like an arrow; gravity is unchanged. Air flight is as before.
* **Mending, Unbreaking, Sharpness, Looting, Lunge** are the vanilla enchantments, allowed by item tags in `data/minecraft/tags/item` (`enchantable/durability`, `sharp_weapon`, `melee_weapon`, `lunge`, and `spears`). Loyalty/Riptide/Piercing are `data/sky_islands/enchantment/*.json`, supported on the item tag `#sky_islands:windspears` and added to the enchanting table, villager trades and random loot through `data/minecraft/tags/enchantment`.
* **Crafting**: the vanilla spear's pattern with breeze rods instead of sticks: the tier's material (planks, stone tool materials, copper ingot, iron ingot, gold ingot or diamond) in the top right, a breeze rod in the middle and another in the bottom left. The netherite one is a smithing upgrade of the diamond Wind Spear (netherite upgrade template + netherite ingot). Change the files in `data/sky_islands/recipe` to taste. There is no creative tab entry yet; use `/give`.
* **Models**: the inventory icon is `textures/item/<tier>_windspear.png` (16x16), held in the hand it shows `<tier>_windspear_in_hand.png` (32x32), and the flying spear uses the in-hand sprite too (`items/<tier>_windspear*.json`).


## Prismarine Stick and Prismarine Axe

Two new items (class `PrismarineItems`, textures/model in `src/client/resources/assets/sky_islands`).

* **Prismarine Stick** (`sky_islands:prismarine_stick`): 2 prismarine shards one above the other (the vanilla stick pattern) make **4** sticks (`recipe/prismarine_stick.json`; change `count` if you want a different yield).
* **Prismarine Axe** (`sky_islands:prismarine_axe`): a real axe (strips logs, scrapes copper, mines like a netherite axe). Recipe, top row left to right: prismarine shard, dark prismarine, prismarine shard; middle row: prismarine shard, prismarine stick; bottom row: nothing, prismarine stick (`recipe/prismarine_axe.json`, mirrored is fine). **11 attack damage** (netherite is 10), **attack speed 1.2**, stone axe durability (131 uses), netherite mining speed and enchantability, repaired with prismarine shards (`tags/item/prismarine_tool_materials.json`). It is in the creative Combat and Tools tabs after the netherite axe, and the stick is in Ingredients after the vanilla stick. The 3D model is converted from `PrismarineSoldier_Axe.glb` (`models/item/prismarine_axe.json`; Minecraft cannot load GLB files, so it was rebuilt as 60 small boxes with the same UVs). Its `display` block (how it sits in the hand, inventory and item frames) is a best guess; tweak it there.
* **Enchantments allowed** (the axe is added to the vanilla tags in `data/minecraft/tags/item/enchantable`, and nothing else is: no Sharpness, Smite, Bane, Fortune, Silk Touch, Fire Aspect, Knockback or Looting):
  * **Mending, Unbreaking**: vanilla (`enchantable/durability`).
  * **Efficiency**: on this axe it changes the attack speed, not the mining speed. Each level adds `EFFICIENCY_ATTACK_SPEED_PER_LEVEL` (+0.1) to the axe's attack speed modifier, which is rewritten on the item itself so the tooltip shows it: I = 1.3, II = 1.4, III = 1.5 ... (`PrismarineItems.updateEfficiency`). Vanilla Efficiency's mining boost is cancelled while the axe is held (a negative transient `mining_efficiency` modifier). Make the constant negative to make Efficiency swing slower instead.
  * **Impaling**: works like Sharpness on the axe (+1.0 damage at level I, +0.5 per level after, against everything, not only sea mobs). `data/minecraft/enchantment/impaling.json` is a copy of the vanilla 26.3 file with two changes: `supported_items` is the new tag `#sky_islands:enchantable/impaling` (tridents + the axe) and the sea-mob bonus is skipped when the attacker holds a Prismarine Axe, so the axe does not get both. Tridents are unchanged.
  * **Density**: `data/minecraft/enchantment/density.json` (vanilla 26.3 copy, `supported_items` now `#sky_islands:enchantable/density`: maces + the axe, so Breach and Wind Burst are still not allowed on the axe). While falling more than 1.5 blocks a hit adds Density's damage per fallen block times the blocks fallen (`PrismarineAxeItem.getAttackDamageBonus`). The mace's big base smash damage is not copied. Impaling and Density can be combined on the axe (both use the exclusive set `#sky_islands:exclusive_set/axe_damage`, which still excludes Sharpness, Smite, Bane of Arthropods and Breach).
  * **Sweeping Edge**: vanilla only allows it on swords and only swords sweep, so the axe gets a sword-style sweep (`PrismarineItems.sweep`): a full-charge, standing, non-sprinting hit sweeps 1 + (Sweeping Edge ratio x attack damage) onto everything within 1 block of the target, with the vanilla sound and slash particle. An axe without Sweeping Edge does not sweep (`SWEEP_NEEDS_ENCHANTMENT`).
* Written without being able to compile, like the rest of the mod. The spots most likely to need a tweak if the build is red: `PrismarineAxeItem` (the `AxeItem` constructor and the `getAttackDamageBonus` override), `ToolMaterial`'s constructor, `AttackEntityCallback`, `ServerLivingEntityEvents.AFTER_DAMAGE`, and `Attributes.SWEEPING_DAMAGE_RATIO`.

## Prismarine Arrow and Prismarine Bow

Two more items (class `PrismarineBows`, plus `mixin/PrismarineBowDamageMixin`; textures and models in `src/client/resources/assets/sky_islands`).

* **Prismarine Arrow** (`sky_islands:prismarine_arrow`): a real arrow item, in the `minecraft:arrows` tag, so the vanilla bow and crossbow shoot it. Recipe like the vanilla arrow, top to bottom: prismarine shard, prismarine stick, prismarine crystals, making **4** arrows (`recipe/prismarine_arrow.json`). Shot from anything but the Prismarine Bow it leaves at **75%** of the normal speed (`ARROW_RANGE_FACTOR`: less range, a little less damage). It **shatters when it lands in a block** (checked every tick; prismarine block-break particles and the stone break sound) and so can never be picked up again. In flight it is **drawn as the Prismarine Arrow item, spinning** like the Wind Spears: the arrow entity is named `sky_islands:prismarine_arrow`, which `client/mixin/PrismarineArrowRenderMixin` takes as "do not draw the plain arrow model", and an item display (`SpearVisual.spawnItem`) follows it each tick (`VISUAL_SCALE` is its size).
* **Prismarine Bow** (`sky_islands:prismarine_bow`): only takes Prismarine Arrows. In creative mode it fires a Prismarine Arrow even with none in the inventory. Recipe: prismarine sticks in the vanilla bow's shape, and the string column is dark prismarine, prismarine crystals, dark prismarine from top to bottom (`recipe/prismarine_bow.json`). **Twice the damage** (`BOW_DAMAGE_MULTIPLIER`, applied to the final hit, Power and Impaling included), **half the durability** of a vanilla bow (192 uses instead of 384, so it wears out twice as fast), and a **draw twice as long** (40 ticks to full power, `DRAW_TIME_MULTIPLIER`; the pull textures in `items/prismarine_bow.json` use half the vanilla scale to match: half pull at 20 ticks, full pull at 36).
  * **Enchantments**: Power, Punch, Flame, Infinity, Mending, Unbreaking and Curse of Vanishing through the vanilla item tags (`tags/item/enchantable/`). **Impaling** is also allowed (`tags/item/enchantable/impaling.json`) and on a bow it acts as extra Power: +0.5 arrow damage per level, the same as one level of Power, so Power V + Impaling V is worth ten Power levels (`enchantment/impaling.json`, which also stops Impaling's aquatic-mob bonus applying to arrows). **Multishot** works too (`enchantment/multishot.json` takes `#sky_islands:enchantable/multishot`: the crossbow tag plus this bow); three arrows, one used, each doing the bow's doubled damage.

## Recipe popups

`RecipeUnlocks` (server) unlocks this mod's recipes the first time the player carries a trigger item, the way vanilla does, and `RecipeToastHud` (client) shows a "Recipe Unlocked!" popup in the top right with the item. The sound is `assets/sky_islands/sounds/ui/recipe_unlock.ogg` (converted from `UI_SFX_Notification.wav`; Minecraft only plays Ogg Vorbis), registered as `sky_islands:recipe_unlock` in `sounds.json`. Triggers: prismarine shard -> Prismarine Stick; prismarine shard, dark prismarine or prismarine stick -> Prismarine Axe; breeze rod or any Wind Spear -> the six crafted Wind Spears; netherite ingot or a diamond/netherite Wind Spear -> the Netherite Wind Spear. The shaped recipes have `"show_notification": false` so vanilla's own popup and sound do not also appear; smithing recipes have no such switch, so the Netherite Wind Spear's unlock also shows vanilla's popup. Edit the groups in `RecipeUnlocks.register`.
